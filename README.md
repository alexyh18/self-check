# 정수리 체크 · 탈모 셀프 측정 앱

정수리 사진을 촬영/업로드하면 **두피 노출도와 모발 밀도**를 분석해
0~100점 건강 점수와 5단계 지표로 알려주는 웹 앱입니다.

> ⚠️ 이 앱은 **의료 진단 도구가 아닙니다.** 사진의 밝기·각도·화질에 영향을 받는
> 참고용 셀프 체크이며, 정확한 진단은 피부과 전문의와 상담하세요.

## 특징

- 📷 **카메라 촬영 / 사진 업로드** 모두 지원 (모바일에서 후면 카메라 바로 호출)
- 🧠 **완전 로컬 분석** — 사진은 기기 밖으로 전송·저장되지 않습니다 (Canvas 기반)
- 📊 **점수 게이지 + 5단계 지표 + 히트맵 오버레이**로 결과 시각화
- 🚫 **의존성·빌드 없음** — 브라우저에서 바로 실행

## 실행 방법

빌드 과정이 없습니다. 로컬 정적 서버로 열면 됩니다
(ES 모듈을 쓰므로 `file://` 직접 열기 대신 서버가 필요합니다).

```bash
cd scalp-check
python3 -m http.server 8099
# 브라우저에서 http://localhost:8099 접속
```

또는 Node가 있다면:

```bash
npx serve scalp-check
```

## 📱 안드로이드에서 실행하기

이 앱은 **PWA(설치형 웹앱)** 로 되어 있어 안드로이드에서 **네이티브 앱처럼** 실행됩니다.

- **가장 빠른 방법 (빌드 불필요):** HTTPS로 호스팅한 뒤 안드로이드 **Chrome**에서 열고
  **⋮ → "앱 설치"** (또는 앱 내 "⬇️ 홈 화면에 앱 설치" 버튼) → 홈 아이콘으로
  전체화면 실행, **오프라인 동작**, 카메라/사진 선택 그대로 지원.
- **Play 스토어용 APK/AAB:** `android/twa-manifest.json` + Bubblewrap(TWA)로 패키징.
- **네이티브 래핑:** Capacitor로 APK 빌드.

👉 상세 단계는 **[`android/README-android.md`](./android/README-android.md)** 참고.

> ℹ️ APK 빌드(TWA/Capacitor)는 인터넷 + Android SDK/JDK가 필요합니다.
> 현재 개발 샌드박스는 외부 네트워크가 차단되어 있어, 여기서는 **PWA까지** 완성해 두었고
> APK 빌드는 네트워크가 열린 PC에서 가이드대로 진행하면 됩니다.

## 분석 로직 요약 (`analysis.js`)

1. 사진 중앙을 정사각형으로 crop → 240×240으로 축소
2. 원형 마스크(정수리 영역)만 분석
3. 각 픽셀을 분류
   - **두피**: 밝고 살색 계열 픽셀 (노출된 두피)
   - **모발**: 어두운 픽셀
4. **중심부에 가중치** 부여 (탈모는 보통 정수리 중앙부터 진행)
5. 두피 노출 비율 → `score`(0~100)와 `stageIndex`(0~4) 산출

| 단계 | 라벨 | 의미 |
|------|------|------|
| 1 | 매우 양호 | 두피 노출 거의 없음 |
| 2 | 양호 | 약간의 노출 |
| 3 | 주의 | 중심부 노출이 눈에 띔 |
| 4 | 진행 | 밀도가 뚜렷하게 낮아짐 |
| 5 | 심화 | 광범위한 노출 |

```
scalp-check/
├── index.html              # 앱 셸 + 파일 입력 + PWA 메타/SW 등록
├── styles.css              # 모바일 우선 다크 UI
├── analysis.js             # 두피/모발 분류 + 점수·단계 산출 엔진

├── icons/
│   ├── icon.svg            # 벡터 아이콘(원본)

│   ├── icon-512.png        # PWA 아이콘 512

```

## 촬영 팁

- 밝은 조명 아래에서
- 정수리가 사진 **중앙(점선 원 안)** 에 오도록
- 두피가 잘 보이도록 가까이에서 촬영

사진에서 두피/모발을 충분히 인식하지 못하면 다시 촬영을 안내합니다.
